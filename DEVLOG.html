سوال: چهار حالت اصلی پیش‌بینی (TP, TN, FP, FN) چه هستند؟
پاسخ: TP (مثبت واقعی): مدل گفت بیمار، واقعاً بیمار بود.
TN (منفی واقعی): مدل گفت سالم، واقعاً سالم بود.
FP (مثبت کاذب): مدل گفت بیمار، واقعاً سالم بود (خطای نوع اول).
FN (منفی کاذب): مدل گفت سالم، واقعاً بیمار بود (خطای نوع دوم - فاجعه‌بار). 		مفهوم: چهار حالت پیش‌بینی
سوال: معیار Accuracy چه چیزی را نشان می‌دهد؟
پاسخ: نسبت کل پیش‌بینی‌های درست (چه بیمار و چه سالم) به کل نمونه‌ها. فرمول: (TP + TN) / Total.
نقطه ضعف: در داده‌های نامتعادل، مدل تنبلی که همیشه کلاس اکثریت را پیش‌بینی کند، Accuracy بالایی می‌گیرد (مثلاً ۹۵٪) اما عملاً هیچ ارزشی ندارد. 		مفهوم: Accuracy (دقت کلی)
سوال: معیار Precision چه چیزی را نشان می‌دهد؟
پاسخ: از میان نمونه‌هایی که مدل به عنوان «مثبت» (مثلاً بیمار) پیش‌بینی کرده است، چند درصد واقعاً مثبت هستند. فرمول: TP / (TP + FP).
کاربرد: وقتی هزینه‌ی FP (ترساندن بی‌مورد افراد سالم) بالاست (مثل فیلتر اسپم). 		مفهوم: Precision (دقت مثبت)
سوال: معیار Recall (یا Sensitivity) چه چیزی را نشان می‌دهد؟
پاسخ: از میان نمونه‌هایی که واقعاً «مثبت» (بیمار) هستند، چند درصد توسط مدل شناسایی شده‌اند. فرمول: TP / (TP + FN).
کاربرد: وقتی هزینه‌ی FN (از دست دادن یک بیمار واقعی) بسیار بالاست (مثل تشخیص سرطان). 		مفهوم: Recall / Sensitivity (بازیابی)
سوال: معیار F1-score چه چیزی را نشان می‌دهد؟
پاسخ: میانگین هارمونیک Precision و Recall است. فرمول: 2 * (Precision * Recall) / (Precision + Recall).
مزیت: از میانگین معمولی استفاده نمی‌کند چون اگر یکی از معیارها صفر باشد، کل F1 صفر می‌شود. برای تعادل بین Precision و Recall و ارزیابی در داده‌های نامتعادل عالی است. 		مفهوم: F1-score (تعادل)
سوال: معیار Specificity (یا True Negative Rate) چه چیزی را نشان می‌دهد؟
پاسخ: از میان افرادی که واقعاً سالم هستند، چند درصد توسط مدل به درستی سالم تشخیص داده شده‌اند. فرمول: TN / (TN + FP).
کاربرد: نشان می‌دهد مدل چقدر خوب افراد سالم را به حال خودشان می‌گذارد و آن‌ها را اشتباهاً بیمار اعلام نمی‌کند. 		مفهوم: Specificity (ویژگی)
سوال: معیار Balanced Accuracy چه تفاوتی با Accuracy معمولی دارد؟
پاسخ: در داده‌های نامتعادل، Accuracy معمولی گمراه‌کننده است. Balanced Accuracy میانگین Recall هر دو کلاس (مثبت و منفی) را حساب می‌کند. فرمول: (Sensitivity + Specificity) / 2.
مثال: مدل تنبل با Accuracy ۶۲٪، Balanced Accuracy حدود ۵۰٪ دارد (چون برای کلاس اقلیت Recall صفر است). 		مفهوم: Balanced Accuracy (دقت متوازن)
سوال: Confusion Matrix چه چیزی را به ما نشان می‌دهد؟
پاسخ: یک جدول ۲×۲ که تمام چهار حالت (TP, TN, FP, FN) را به تفکیک نشان می‌دهد.
مثال در پروژه: در ماتریس [[37, 1], [1, 75]]، مشخص است که مدل ۲ خطا (۱ FP و ۱ FN) داشته است. 		مفهوم: Confusion Matrix (ماتریس درهم‌ریختگی)
نتیجه: هیچ معیار واحدی برای همه مسائل بهترین نیست.
- داده متوازن است؟ → Accuracy.
- نباید بیمار از دست برود؟ → Recall.
- نباید فرد سالم را بیمار اعلام کنیم؟ → Precision.
- تعادل بین هر دو؟ → F1-score.
- داده نامتعادل است؟ → Balanced Accuracy.
- جزئیات خطاها؟ → Confusion Matrix. 		نتیجه: راهنمای انتخاب معیار ارزیابی
